Frame Timer

Privacy Policy

Last updated: September 9, 2026

Frame Timer does not collect, store, or transmit any personal data. It has no network access, no analytics, and no third-party services. It is a simple, offline, on-device stopwatch.

What data the app uses

Frame Timer only keeps the data needed to run the on-screen stopwatch during the current app session — the frame rate you selected (24p, 25p, 30p, 48p, 50p or 60p) and the running timer state. This information is held in memory on your device only, is never written to disk, never leaves your device, and is discarded as soon as you close or reset the app.

Data collection and analytics

Frame Timer does not use any analytics, crash reporting, advertising, or tracking frameworks, first-party or third-party. No usage data, device identifiers, or diagnostic information is collected or transmitted anywhere.

Network access

Frame Timer does not require, request, or use any network or internet connection to function. Everything runs entirely on your device.

Third-party services

Frame Timer does not integrate with any third-party SDKs or services.

Children's privacy

Because Frame Timer collects no personal data from anyone, it does not knowingly collect personal data from children.

Changes to this policy

If this policy ever changes — for example, if a future version of the app adds a feature that uses data differently — this page will be updated and the "Last updated" date above will reflect the change.
